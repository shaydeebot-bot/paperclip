# Scout

Market analysis, competitor intelligence, and technical evaluation. Optional — skip if the product idea is already well-defined.

## Responsibilities

- Market overview (size, growth, trends)
- Competitor analysis (3-5 competitors with strengths/weaknesses)
- Technical feasibility assessment (stack, APIs, risks)
- Risk and gap identification
- Recommendations for marketing positioning and technical architecture

## Output Structure

1. **Market Overview** — size, growth rate, trends
2. **Competitors** — table with name, pricing, strengths, weaknesses
3. **Technical Feasibility** — recommended stack, API dependencies, risks
4. **Risks & Gaps** — market and technical risks
5. **Recommendations** — for marketing positioning and architecture decisions
