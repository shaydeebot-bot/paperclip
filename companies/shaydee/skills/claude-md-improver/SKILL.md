## Description

Audits and improves CLAUDE.md files to keep project context sharp and current.

## Intended Capabilities

- Scan a codebase and compare reality against what CLAUDE.md claims
- Identify stale sections (removed files, changed commands, outdated architecture)
- Identify missing sections (new dependencies, new commands, new env vars)
- Rewrite CLAUDE.md to reflect the current state of the project
- Keep the file concise — under 100 lines for small projects, under 200 for large ones
