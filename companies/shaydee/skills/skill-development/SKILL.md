# Skill Development

## Description

Ensures new skills are well-structured: progressive disclosure, strong trigger descriptions, correct writing style.

## Intended Capabilities

- Validate skill structure (YAML frontmatter, markdown body, bundled resources)
- Check that trigger descriptions are specific and "pushy" enough to avoid undertriggering
- Verify progressive disclosure (metadata -> SKILL.md body -> bundled resources)
- Review writing style: imperative form, explain-the-why over rigid MUSTs, general not narrow
- Ensure SKILL.md stays under ~500 lines with clear pointers to reference files
- Check that domain-specific skills organize by variant with separate reference files
